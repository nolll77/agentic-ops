## Executive Summary & Design Invariant

The **`Agentic-Ops` Model Context Protocol Gateway** (`agentic_ops/entrypoints/mcp_server.py`) operates as a governed control plane connecting external cognitive agents (`Claude Desktop`, `Cursor`, `Windsurf`, `Google Antigravity`, `OpenRouter`) to production infrastructure.

Unlike conventional CRUD or unstructured tool gateways, `Agentic-Ops` adheres to the **Deterministic Firewall Invariant**:
> *Cognitive models propose hypotheses; deterministic, zero-token Python kernels enforce policy boundaries, compute blast radiuses, and seal immutable cryptographic evidence.*

This roadmap formalizes the three upcoming engineering phases designed to evolve the gateway from a synchronous execution endpoint into an autonomous, distributed, and cryptographically provable MLOps nervous system.

## Phase 1: Real-Time Sensory Probes & Streaming Telemetry

### 1.1 Objective & Context
Currently, `Agentic-Ops` exposes 8 governed MCP tools and 5 knowledge resources via synchronous HTTP `POST /mcp` (Streamable JSON-RPC 2.0) and local `stdio`. While suitable for transactional queries, high-throughput MLOps incident response requires continuous sensory observation without client-side polling loops.

### 1.2 Architectural Deliverables

1. **Dual Transport Support (`SSE` + `Streamable HTTP`)**:
   - Introduce native Server-Sent Events (`SSE`) endpoint at `GET /mcp/events` alongside the existing `POST /mcp`.
   - Maintain full backwards compatibility with Anthropic MCP protocol version `2024-11-05`.
   - Implement client session heartbeat and automatic reconnection handling with zero state loss.

2. **Streaming Telemetry over Dynamic MCP Resources**:
   - Expose dynamic URI schemes:
     - `mlops://telemetry/live/drift`: Continuous streaming of calculated Wasserstein distance and Kolmogorov-Smirnov drift statistics generated by `Evidently AI`.
     - `mlops://telemetry/live/latency`: Sub-second P95/P99 latency feeds collected from Prometheus endpoints.
   - External LLMs can subscribe to resource notifications (`notifications/resources/updated`) rather than polling `poll_target_mlops_snapshot`.

3. **Dynamic Prompt Sampling (`sampling/createMessage`)**:
   - Implement MCP server-initiated prompt sampling allowing the control plane to delegate localized heuristic evaluation back to the connected client model.
   - Enables interactive Human-in-the-Loop (`HITL`) step confirmation inside IDEs (`Cursor`, `Claude Desktop`) prior to executing `REQUIRE_APPROVAL` tier actions.

### 1.3 Technical Verification Criteria
- [ ] SSE connection benchmark: sustain 50 concurrent SSE streaming connections with $< 15\,\text{ms}$ event dispatch latency.
- [ ] Non-blocking event loop: ensure streaming sensory telemetry does not block synchronous tool calls in `mcp_server.py`.
- [ ] Zero-drift schema validation: ensure all streamed event payloads adhere to strict Pydantic v2 schemas (`TelemetrySnapshot`).

## Phase 2: Cryptographic Auditability & EU AI Act Compliance

### 2.1 Objective & Context
Regulatory frameworks for autonomous systems—most notably the **European Union Artificial Intelligence Act (`Regulation (EU) 2024/1689`)**—mandate strict record-keeping (Article 12: *Record-keeping*) and human oversight (Article 14: *Human oversight*) for high-risk autonomous AI systems operating in critical workflows.

Phase 2 embeds mathematical proof generation directly into the MCP protocol interface.

### 2.2 Architectural Deliverables

1. **Native `verify_ledger_inclusion` Governed MCP Tool**:
   - Expose a new governed tool:
     ```python
     def verify_ledger_inclusion(
         episode_id: str,
         leaf_index: int,
         expected_merkle_root: str
     ) -> Dict[str, Any]:
         """Verifies an RFC 6962 audit path proof in O(log N) time."""
     ```
   - Connects directly to `agentic_ops/core/merkle_tree.py` (`RFC6962MerkleTree`).
   - Returns a structured proof audit certificate:
     - Sibling audit path hashes: `[\"0x00...\", \"0x01...\"]`.
     - Calculated root vs expected root equality verdict (`MATCH` / `TAMPERING_DETECTED`).
     - Computational verification complexity: $\mathcal{O}(\log_2 N)$ hashing operations.

2. **Automated EU AI Act Article 12 Compliance Bundle**:
   - Expose an MCP resource `mlops://compliance/eu-ai-act/article-12/audit-pack` providing a consolidated, cryptographically signed export containing:
     - Continuous WORM event log (`ledger.jsonl`).
     - SHA-256 linear hash chain continuity certificate.
     - Deterministic Policy Engine decision traces with 0-token veto logs (`R-001` to `R-005`).
     - Operator approval records with HMAC-SHA512 cryptographic signatures.

3. **Tamper Rejection Proof in CI/CD**:
   - Add automated adversarial test cases validating that any single-bit flip in historical episode logs causes immediate tool-level verification failure with explicit diagnostic codes.

### 2.3 Technical Verification Criteria
- [ ] $\mathcal{O}(\log N)$ proof generation executes in $< 2\,\text{ms}$ for ledgers exceeding $10^5$ episodes.
- [ ] Cryptographic tool suite fully audited by automated pytest cases in `tests/entrypoints/test_mcp_server.py`.
- [ ] 100% compliance with RFC 6962 specification for leaf hashing prefix (`0x00`) and interior node hashing prefix (`0x01`).

## Phase 3: Judicial Multi-Agent Quorum & Sovereign Mesh

### 3.1 Objective & Context
Allowing a single AI agent or single LLM provider to both formulate remediation plans and validate their safety creates an unacceptable single point of failure and systemic cognitive bias. Phase 3 introduces **Judicial Quorum Governance** and **Sovereign Mesh Fallbacks**.

### 3.2 Architectural Deliverables

```text
                               +----------------------------------+
                               |     INCIDENT DETECTED VIA        |
                               |    STREAMING TELEMETRY (P1)      |
                               +-----------------+----------------+
                                                 |
                                                 v
                               +----------------------------------+
                               |   PROPOSER AGENT (e.g. Claude)   |
                               | Formulates ActionProposal:       |
                               | "Scale replicas + flush buffer"  |
                               +-----------------+----------------+
                                                 |
                                                 v
           +-------------------------------------+-------------------------------------+
           |                                                                           |
           v                                                                           v
+-----------------------+                                                   +-----------------------+
|  DETERMINISTIC KERNEL |                                                   |    INSPECTOR AGENT    |
| (agentic-ops Policy)  |                                                   |   (Judicial Quorum)   |
| Pure Python 0-Token   |                                                   | Independent Model     |
| * Blast radius < 0.2  |                                                   | (e.g. DeepSeek / Llama|
| * Rate limit check    |                                                   | via sovereign node)   |
| * Upstream masking    |                                                   | * Evaluates rationale |
+-----------+-----------+                                                   +-----------+-----------+
            |                                                                           |
            +-------------------------------------+-------------------------------------+
                                                  |
                                                  v
                               +----------------------------------+
                               |    CONSENSUS & EXECUTION GATE    |
                               | BOTH Verdicts Must Be "PASS"     |
                               | If approved -> Execute & WORM    |
                               | If vetoed    -> Abort & Log      |
                               +----------------------------------+
```

1. **Judicial Separation of Powers (Proposer vs Inspector)**:
   - Split cognitive roles during incident remediation:
     - **Proposer Agent**: Generates diagnostic hypotheses and drafts an `ActionProposal`.
     - **Inspector Agent (Auditor)**: Operates under a separate LLM family with independent prompt constraints. Audits the proposal for hidden side effects, unstated assumptions, or subtle drift masking.
   - Execution is blocked unless both the **Deterministic Policy Engine** AND the **Inspector Quorum** emit an uncompromised approval.

2. **Sovereign Encrypted Mesh Routing (`Tailscale` + `Ollama`)**:
   - Deepen integration with `agentic_ops/adapters/cac_pull_collector.py` and private mesh networks.
   - In the event of cloud provider partition, rate-limiting (`HTTP 429`), or network cutoff:
     - MCP server automatically routes tool calls and prompt evaluations over encrypted WireGuard tunnels (`Tailscale`) to on-premises sovereign inference nodes (`Ollama` running `qwen2.5-coder` or `deepseek-r1`).
     - Guarantees $100\%$ air-gapped emergency remediation capability with zero external cloud dependencies.

3. **Multi-Cluster Federation**:
   - Allow a master `Agentic-Ops` MCP gateway to orchestrate worker nodes across heterogeneous Kubernetes clusters and bare-metal environments via authenticated mutual TLS (`mTLS`) or WireGuard overlays.

### 3.3 Technical Verification Criteria
- [ ] Judicial quorum consensus verified under simulated adversarial prompt injections (`SC-101`, `SC-102`).
- [ ] Automatic failover to local sovereign node executes in $< 500\,\text{ms}$ upon external API failure.
- [ ] Zero regression across the existing 231 unit and integration tests.
